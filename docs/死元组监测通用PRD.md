# 高斯数据库死元组监测采样 —— 业务需求与功能设计说明书

## 一、 整体设计原则

1. **单一页面分栏布局**：采用左侧配置、右侧看板的左右分栏（Master-Detail）单页结构，聚焦高斯死元组监测场景。
2. **后端与存储完全通用**：采样结果表不绑定任何死板的业务列，忠实记录自定义 SQL 执行后的每一行原始数据（以 JSON 形式平铺存储），为未来扩展其他监控指标奠定坚实底座。
3. **前端业务垂直闭环**：当前版本专属服务于死元组清理效率分析，后续若扩展其他类型的采样监测，后端逻辑保持不变，仅由前端开发全新页面。

---

## 二、 页面布局与功能模块划分

### 1. 左侧：采样任务配置区 (`Task Sidebar - Master`)

- **核心职责**：管理所有死元组监测任务的创建与列表切换。
- **主要功能元素**：
  - **顶部入口**：`[新建死元组采样任务]` 按钮。
  - **任务列表**：展示任务名称、关联的数据库连接、当前运行状态。
  - **联动交互**：点击任意任务项，右侧内容区域实时切换，加载对应任务的详情与波动图。

- **新建/编辑任务弹窗**：
  - **基本信息**：任务名称。
  - **数据源选择**：复用现有的“数据库连接配置”。
  - **采样类型 (`sampling_type`)**：预设/固定为 `DEAD_TUPLE`（死元组监测采样），为后台通用架构做类型标识。
  - **自定义 SQL**：内置高斯死元组查询模板（如查询 `pg_stat_user_tables`）。
  - **采样计划**：设定起止时间窗口与采样频率（如高频采样：每 2 秒 1 次）。

---

### 2. 右侧上方：任务概要与控制区 (`Task Summary Bar`)

- **核心职责**：展示当前选中任务的“身份证”与生命周期控制。
- **主要功能元素**：
  - **基本属性**：展示关联的数据库连接、完整的自定义 SQL 预览、采样频率、起止时间窗口。
  - **状态与生命周期控制**：
    - 状态标识（运行中 / 已停止 / 已完成）。
    - **操作按钮**：`[启动]` / `[停止]`、`[编辑任务]`、`[删除任务]`。

---

### 3. 右侧下方：死元组波动图看板区 (`Fluctuation Dashboard - Detail`)

- **核心职责**：通过高频采样的历史数据，直观呈现高斯数据库的死元组累积与清理效率。
- **主要功能元素**：
  - **筛选与指标卡片栏**：
    - **表名筛选（Entity 动态过滤）**：支持下拉选择或搜索具体的表名（由底层结果 JSON 动态解析而来）。
    - **时间范围选择**：最近 1 小时、最近 6 小时、自定义时间段等。
    - **核心指标卡片**：展示当前选中表的“最新死元组数”、“当前死元组占比”、“最近一次清理时间”。

  - **波动图表区（核心展示）**：
    - **死元组数量波动趋势图**（折线图）：横轴为时间（如 2 秒间隔的时间点），纵轴为死元组数量。通过观察波峰（业务高频增删改导致的死元组累积）与波谷（Autovacuum 触发后的清理下降），直观评估清理效率是否健康。

## 三、 数据存储与模型设计要点

为确保后台逻辑的绝对通用性，数据表设计保持极简和解耦：

### 1. 采样任务表 (`sampling_task`)

- **核心字段**：

| 字段 | 说明 |
| --- | --- |
| `id` | 任务ID |
| `task_name` | 任务名称 |
| `connection_id` | 复用的连接ID |
| `sampling_type` | 采样类型，当前为 `DEAD_TUPLE` |
| `custom_sql` | 自定义SQL |
| `start_time` | 开始时间 |
| `end_time` | 结束时间 |
| `frequency` | 采样频率 |
| `status` | 任务状态 |

### 2. 通用结果明细表 (`sampling_history`)

- **核心字段**：

| 字段 | 说明 |
| --- | --- |
| `id` | 主键 |
| `task_id` | 关联的任务 ID |
| `sampling_time` | 采样时间戳（同一批次执行拿到的多行数据共享此时间戳） |
| `row_data` | **纯通用 JSON 大字段**。不设任何业务列，SQL 查出来的一行数据是什么样，就原封不动地序列化存入此字段（例如：`{"relname": "orders", "n_dead_tup": 1500, "n_live_tup": 5000}`） |
