# SQL 变更脚本（Flyway 管理）

本目录存放所有数据库变更脚本，由 **Flyway** 在应用启动时**自动执行**，**禁止**手工执行 SQL 脚本。

## 命名规范

按版本顺序命名，格式为 `V[主版本].[次版本]__[描述].sql`，例如：

- `V1.0__init.sql` — 初始建表脚本
- `V1.1__performance_meta_resource.sql` — 性能测试 + 造数引擎 + 资源核查模块建表
- `V1.2__create_wiki_document.sql` — Wiki 文档模块建表

## 执行方式

无需手工执行。后端应用启动时，Flyway 会自动扫描 `classpath:db/migration`（由 Maven 构建时将本目录 `V*.sql` 复制到该路径），按版本顺序依次执行，并将执行记录写入 `flyway_schema_history` 表。

```bash
# 仅需启动后端服务即可自动迁移
mvn spring-boot:run
```

## 注意事项

- **严格按版本顺序执行**，Flyway 自动保证，不要跳过中间版本。
- **禁止修改已执行过的历史脚本**（Flyway 校验失败会阻止启动）。如需变更，请新增更高版本脚本（如 `V1.3__xxx.sql`）。
- 每个脚本应幂等，支持重复执行不报错（如使用 `CREATE TABLE IF NOT EXISTS`、`DROP TABLE IF EXISTS`）。
- 首次启动时 `baseline-on-migrate: true` 会自动创建基线，兼容已有数据库。

## SQL 编写规范

- PostgreSQL 16+ 语法
- 字符集 UTF-8（数据库默认）
- 所有字段必须通过 `COMMENT ON COLUMN` 补充注释
- 核心审计字段命名：`create_time` 和 `update_time`，默认 `CURRENT_TIMESTAMP`
- 核心业务表主键：`VARCHAR(32)`，使用雪花 ID
- 涉及 AI 向量检索的表，脚本开头执行 `CREATE EXTENSION IF NOT EXISTS vector;`，向量字段使用 `vector(n)` 类型
- 自增主键使用 `GENERATED BY DEFAULT AS IDENTITY`
- 模拟 MySQL `ON UPDATE CURRENT_TIMESTAMP`：使用触发器函数 `set_update_time()` / `set_last_time()`
